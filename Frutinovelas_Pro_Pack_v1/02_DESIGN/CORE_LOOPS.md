# CORE LOOPS

## Loop A — Merge/Trabajo
1. Entrar al tablero.
2. Tocar generador.
3. Recibir objetos.
4. Fusionar pares.
5. Completar pedido.
6. Obtener Frutimonedas + XP.
7. Desbloquear pedido nuevo.
8. Alcanzar hito → Estrella.

## Loop B — FrutiCombo
1. Seleccionar nivel.
2. Ver objetivo.
3. Jugar 60–180 s.
4. Crear especiales y cascadas.
5. Ganar.
6. Obtener Frutimonedas / energía / Estrella según hito.

## Loop C — Casa
1. Gastar Estrella.
2. Activar tarea de reforma.
3. Elegir una de 3 variantes.
4. Cambia visualmente la habitación.
5. Se dispara microescena.
6. Siguiente tarea.

## Loop D — Frutinovela
1. Notificación de conflicto.
2. 2–5 líneas de diálogo.
3. Nuevo objetivo.
4. Gameplay.
5. Resolución.
6. Cliffhanger ligero.

# Onboarding ideal
### Minuto 0
Mona descubre que la cocina está hecha un desastre.

### Minuto 1
Tutorial de merge de 2 objetos.

### Minuto 2
Primer pedido completo.

### Minuto 3
Primera Estrella.

### Minuto 4
Primera reforma.

### Minuto 5
Pablo entra con un paquete equivocado y abre el segundo problema.

### Minuto 6–8
Primer FrutiCombo.

Objetivo: el jugador debe haber probado los 4 pilares antes de 10 minutos.
