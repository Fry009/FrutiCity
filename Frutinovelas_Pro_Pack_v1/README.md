# FRUTINOVELAS — PRO PACK v1

Base de diseño y producción para un videojuego casual mobile-first desarrollado en Unity.

## Objetivo
Construir primero un MVP para Android, dejando preparada la arquitectura para iOS.

## Identidad del juego
Frutinovelas mezcla:
- personajes-fruta con profesiones y personalidad;
- tablero de merge para fabricar objetos de trabajo;
- puzzle match-3 corto y muy rejugable;
- casa decorable;
- episodios de comedia/drama ligero;
- progresión mediante Estrellas, Frutimonedas y habilidades de personaje.

## MVP
- 6 personajes jugables/narrativos.
- 3 profesiones con cadenas merge completas.
- 50 niveles match-3.
- 3 habitaciones.
- 30 muebles/variantes.
- 10 episodios.
- Guardado local.
- Economía básica.
- Ads/IAP desactivables y preparados, no obligatorios para prototipo.

## Resolución de referencia
Diseño vertical: 1080 x 1920.
UI con Canvas Scaler en `Scale With Screen Size`.
Referencia: 1080x1920, Match 0.5.

## Regla de producción
Primero diversión y claridad. Después contenido. Después monetización.
